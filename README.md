# Multi-Model Defect Detection Framework

A unified defect detection application supporting YOLOv5, YOLOv8, and YOLOv9.

## Features

- Unified interface for YOLOv5/v8/v9
- Model switching with independent rendering
- Batch processing

## Tech Stack

- Python, PyTorch
- YOLOv5, YOLOv8, YOLOv9
- PyQt5

## Setup

1. Install dependencies from requirements.txt (if available)
2. Download model weights (not included in this repo)
3. Run: python main.py

> Model weight files and datasets are not included due to size.
